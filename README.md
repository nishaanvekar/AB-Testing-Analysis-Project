# A/B Testing Analysis Python Project

## Overview
This project analyzes an A/B test conducted on a webpage to compare conversion rates between two variants.
This Project is performend on Google Colab (browsing site)
---

## Dataset

* 1000 users
* Group: A/B
* Device: Mobile/Desktop
* Time Spent
* Conversion (0/1)

---

## Tools Used

* Python
* Pandas
* Seaborn
* Statsmodels

---

## Analysis Performed

* Conversion rate comparison
* Segmentation by device
* Z-test and P-value for statistical significance
* Uplift calculation
* Confidence interval estimation

---

## Key Insights

* Variant B shows higher conversion rate
* Uplift observed between variants
* Mobile users respond better
